# 思政智教 · 智慧课堂平台

AI 赋能思政课堂教学设计平台，适配省级思政课教学设计比赛。

## 功能模块

- 📊 **教学概览** — 数据看板 + 教学日程
- 📚 **课前资料** — 发布文本/视频/音频，追踪学习进度
- 🎯 **课堂互动** — 实时出题、在线作答、AI 学情分析
- 📝 **课后任务** — 发布任务、查看完成情况
- 🏆 **学生作品** — 作品展示与批改
- 📈 **学情分析** — 数据报告 + AI 教学建议
- 🐴 **湘小马 AI** — 智能教学助手（点击右下角）

## 启动方式

### Windows
双击 `start.bat`

### Mac / Linux
终端运行 `bash start.sh`

### 手动启动
```bash
# 在本目录下运行
python3 -m http.server 8080
# 浏览器打开 http://localhost:8080
```

## 要求

- Python 3（系统自带，无需额外安装）
- 现代浏览器（Chrome / Edge / Firefox / Safari）
